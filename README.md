# 边境 · 探索生存 0.16.1

一个运行在 SillyTavern / TauriTavern 前端的探索生存扩展。区域地图、普通地块、洞穴与建筑内部、资源点、容器、物品、建设和存档都由插件管理。正式游戏直接调用独立的 Chat Completions API，不使用酒馆正文生成，也不解析 Markdown 地图或表情图标。

## 开始使用

### 从 GitHub 安装（推荐）

打开酒馆的 **扩展 → 安装扩展**，粘贴以下仓库地址；若有分支选项，填写 `main`：

```text
https://github.com/agentgeleven-lab/sillytavern-frontier-survival
```

安装后刷新酒馆，点击左下角 **边境 · 探索**。这是 `0.16.1` 预览版；真实宿主与外部模型的验证范围见文末。更新时使用酒馆的扩展更新功能。

### 手动安装与首次游玩

1. 将整个 `frontier-survival` 文件夹放入酒馆的用户扩展目录 `data/<用户>/extensions/`。`manifest.json` 必须直接位于该文件夹内，不要再多嵌套一层。也可放入宿主支持的全局 `extensions/third-party/` 目录。
2. 刷新酒馆。点击左下角 **边境 · 探索**，或在扩展设置中点击打开按钮。
3. 点击 **先体验离线演示**，先试地图、开门、搜索、拿取与建设。
4. 正式游玩：在 **游戏设置** 填写独立 API 地址、模型 ID、可选密钥并保存。地址支持 `https://example.com/v1` 或完整 `/chat/completions` 地址。
5. 新游戏界面可以读取当前角色卡与其主绑定世界书，也可以读取角色卡 JSON，或自行填写背景。检查背景文本后，通过独立 API 创建游戏。

无需构建、Node 服务插件或额外依赖。离线开发预览需使用 HTTP 服务打开 `preview.html`，不支持直接双击 `file://` 运行模块。

## 当前版本能做什么

- 世界地图按需扩展：每个世界格容纳一个区域，支持负坐标与四方向持续探索；只绘制视野附近的格子。
- 区域大小：小 9×9、普通 15×15、大 21×21。由种子与世界坐标预先确定，界面只显示，不再手动选择；已有区域保持原尺寸。
- 相邻区域使用共享边界约束与对应入口，参考已生成邻区的边界和地形；模型输出必须通过边界与连通校验。
- 建筑大小上限：小 12×12、普通 24×24、大 40×40。建筑在区域生成时按用途确定大小，首次进入不会再让玩家选择；实际室内可小于上限。
- 模型描述实际宽高、房间矩形、门窗和家具坐标，插件生成网格。允许小于上限及不规则轮廓，建筑外部空白不可通行；校验出口、房间与容器可达性。
- 局部移动：选择地面并移动；选择容器或门后可自动走近，接着单独开门或搜索。关闭的门与墙体阻挡视线；已经看过的布局保留为记忆。
- 容器：独立生成战利品一次；物品先留在容器，点击拿取进入背包。离开再回来不会刷新。
- 区域快速搜集与地块内逐点采集共用物资余量；支持负重、补给、休息、时间与天气状态、健康/饱食/水分/体力。
- 简易庇护所及加固配方，扣除材料、消耗游戏时间，支持营地储藏与取出。正式模式会独立调用模型生成建设描述。
- 每个聊天单独存档，浏览器/宿主本地持久保存；支持 JSON 导入导出。无角色聊天时使用独立临时范围。
- 聊天发送前注入已知游戏现场。聊天完成后使用独立 API 提取线索与明确地点发现；不需要正文输出标签。
- 传闻不会直接创建战利品。未知坐标保留为待定位；冲突地点保留为待核对。可以撤销线索。
- 编辑、删除或切换消息时撤回其尚未实地探索的发现；已经探索的世界事实保留。
- 请求失败/取消不结算；切换聊天后迟到的 API 结果不会写入另一局游戏。

## 地理环境与地图表现

- 环境先由插件计算，独立模型在固定约束下补充地图。气候分寒冷、温带、干旱、热带；生态包括森林、草原、湿地、山地、海岸、荒漠、寒原和雨林。同类生态连片过渡。
- 聚落独立叠加：农村、小镇、城市郊区、城市和工业区围绕稀疏的聚落中心分布，绝大部分世界为无人荒野；“荒野独居”主题进一步降低聚落密度。废弃/破损状态仅作用于人工地点。
- 无人区生成 **零建筑**，内部不生成城市街区、农田和道路；与旧区域衔接时允许继承边界。自然地点有枯木林、野果丛、林间空地、泉眼、芦苇丛、岩洞、岩台、漂流木滩，按生态选择。
- 普通陆地和自然地点都可进入周边地块；岩洞可从地块内的洞口进入独立洞穴，再返回原入口。天然水不会直接变为饮用水，净水和更细的采集配方后续加入。
- 前端使用 Canvas 绘制浅色纸面、地形纹理、树木岩石、农田、屋顶及营地图形；室内用木地板、砖墙、窗和家具形状表达。世界缩略图只包含已经发现的格子与地点。
- 地形信息会加入聊天的已知现场；隐藏地点和生物栖息地内部数据不会注入。
- 生物系统现已加入基础野生动物、移动、感知、逃跑、捕食和迁入，详见 0.9.0。基础近战、驱赶和尸体处理现已加入；尚无繁殖或完整食物链模拟。

旧存档保留原来的区域与建筑；新地图绘制立即生效，生态生成只用于新区域，不重生成已探索地点。

## 多层地图与跨区域探索

地图上方使用 **世界／区域／地点** 切换视图。切换只改变查看范围，不移动角色、不消耗时间。

1. 在世界地图选择一个相邻格子，也可用右侧的东南西北按钮定位。
2. 未生成格子的大小已确定。点击 **探索这片区域** 才调用 API；离线演示使用确定性生成器。
3. 旅行包括走到当前区域出口及跨区的 30 分钟，界面会显示预计总耗时。成功后从目标区域对应方向的入口出现。
4. 返回旧区域直接读取原存档，保留迷雾、柜子物资、营地和当地线索，不重新生成。生成失败、取消、存储失败或其他窗口已修改存档时，不结算本次旅行。
5. 目前逐个相邻区域旅行；在地块或室内须逐层走到出口离开，再进行区域旅行。世界格子显示已发现地形的缩略图；大小、探索程度和营地数量放在右侧详情中。

旧存档自动成为世界 `(0,0)` 的小区域；原地图、建筑、战利品和营地保留。旧区域只在原有可达边缘建立出口，不重画地形；某一侧没有可达陆地时，需要从其他方向探索。

## 操作示例

演示内容随种子与坐标变化，大部分起点位于无人荒野：

1. 填写种子，点击“先体验离线演示”。可用 `testing` 体验森林无人区。
2. 地图默认放大到当前位置附近；拖动查看周边，点击“全图”查看整个区域。
3. 选择已知格子前往，可以直接快速搜集，或进入周边地块，选择资源点、走近、逐份采集。两种方式共用余量。
4. 找到建筑后探索内部，靠近门或容器，再开门、搜索与拿取。
5. 切换世界地图，选择相邻区域并探索；返回会保留原来的地图和物资。

探索不会替你发送聊天消息。点击动作按钮会直接执行插件内动作；地图选择与面板切换不消耗游戏时间。

## 聊天同步边界

- “NPC 说旧医院地下室可能有药”：新增传闻，不保证存在，不增加背包物品。
- “我发现了 (3,4) 的旧医院”：经过信息提取、证据与坐标校验后，允许补充不冲突的地点。
- “我希望附近有医院”：提取提示要求忽略愿望与假设；模型仍可能误判，记录可撤销。
- 自动定位只接受明确区域坐标、已有同名地点、或明确的“这里/此处”。仅有“北边”先保留待定位记录。
- 第一版不自动执行聊天里的交易、受伤、角色死亡和建设。它们需要后续专门规则。
- 自动提取会消耗独立 API 请求；可以关闭自动同步或现场注入。
- 插件仅向聊天提供已知地点与已搜索容器信息。全图与未搜索物资不会默认进入现场摘要。
- 主角色卡和主绑定世界书以背景文本快照保存，最长 30,000 字符；超过部分截断。初版不自动读取全局、额外绑定和关键词激活世界书，群聊请通过 JSON 或文本明确提供背景。

## 独立 API 与存档

### 多套 API 方案与模型列表

在 **游戏设置 → 独立 LLM API** 管理方案：

1. 输入方案名称，点击 **按此名称新建空白方案**；或者填写连接信息后改用新名称，点击 **另存为新方案** 复制当前表单。
2. 填写 API 地址与可选密钥，点击 **拉取模型**，从接口模型列表中选择模型；也可直接手动填写模型 ID。
3. 点击 **保存并使用当前方案**。方案分别保存地址、模型、最大输出、超时、温度与密钥保存选项。
4. 使用 **当前方案** 下拉框切换；切换会放弃未保存的表单修改。刷新后恢复上次所选方案。修改名称后保存即可重命名；可删除多余方案，至少保留一套。

旧版单套配置会自动迁移为“默认方案”。方案属于当前酒馆用户，供各聊天使用；游戏存档仍按聊天分开。每套方案的密钥默认只留在本次页面会话；需要跨刷新保存时，请单独勾选该方案的本机持久保存选项。

拉取模型发送 `GET /models`，沿用所填 API 地址的路径前缀和密钥，支持从完整 `/chat/completions` 地址推导模型列表地址。无需先选择模型，也不消耗聊天生成。接口不支持模型列表、鉴权失败或跨域受限时会提示原因，仍可手动填写。切换方案或修改地址/密钥会取消旧列表请求。

### 请求与本地存储

超时秒数没有 300 秒上限，填写 `0` 表示插件不自动超时，新方案默认不限时。已有方案保留原值，可改为 `0` 后保存。生成与拉取模型共用此设置，手动取消和切换聊天/方案的取消机制仍然有效。接口服务或代理自身的超时限制仍由服务端决定。

只支持兼容 Chat Completions 的非流式接口。背景与当前行动需要的游戏信息会发送至你填写的接口；聊天同步会发送目标消息和前两条短上下文。不会读取或复用酒馆的 API 密钥，也不会修改其连接配置。

浏览器直连要求服务支持当前宿主来源的跨域请求（CORS）。如果地址只能由服务器调用，第一版无法直接连接；不会悄悄改用酒馆主生成。

密钥默认仅保存在当前页面内存；关闭/刷新页面后重新填写。勾选“在本机持久保存密钥”会将密钥以明文存入当前宿主的本地存储。它不进入游戏存档、背景或聊天提示。未内置、不附带任何密钥。

游戏使用 IndexedDB 分区保存，按当前酒馆用户和聊天隔离。内存保留当前区域及世界摘要；普通行动只写当前区域，跨区在同一事务中保存离开和进入的区域。首次读取旧版 localStorage 存档时迁移到新存储，原始记录保留。API 方案仍保存在 localStorage。

导出 JSON 包含整个世界及全部区域；导入也支持旧版单区域 JSON。更换前端来源、清理应用数据可能导致本地存档不可用，请定期导出。没有服务器端存档同步。世界没有预设游戏边界，实际容量仍受设备内存和浏览器存储空间约束；整个世界导出时需要读取全部区域。

## 当前范围与限制

- 世界可以按需拓展，目前只支持相邻区域逐步旅行，未加入自动多区域路线和离线生成队列。
- 聊天线索按区域隔离；当前只提取当前区域的坐标与发现。世界坐标和当前区域尺寸会注入聊天；明确指向其他区域的线索暂不自动放置。返回旧区域时会重新核对其消息来源，已探索地点保留。
- 地块、洞穴和建筑各自单层、一个返回出口；洞穴与建筑从周边地块进入后返回原入口，也保留区域直接进入建筑的快捷入口。窗户暂时只能透视，未实现翻窗、锁具、破坏与多楼层。
- 基础物资、武器制作、两级庇护所及设施、食物批次与外伤系统；未实现人类 NPC 实体模拟、交易或任意自由行动。
- 天气会随游戏时间变化，但复杂温度、装备保暖与疾病尚未加入。
- 资源点没有生长恢复；本版石料可收集和储藏，采矿工具与石料建设配方尚未加入。种子稳定控制演示地图；正式模型即使使用同一种子，也不保证跨新游戏生成完全相同的世界。单局已保存世界保持稳定。
- 线索提取有逐字证据、坐标及类型检查，但语义判断仍依赖模型；误判可在日志面板撤销。
- 模型地图如果结构不合法，会自动请求一次修正；仍不合法就报错并保持原存档。

### 0.3.0 验证范围

54 项 Node 测试通过，覆盖自然区域零建筑、样本世界自然占比与连片性、固定大小、地点校验、迷雾摘要和旧存档回归。浏览器内 11 项真实 IndexedDB 检查和 6 项本地模拟 API 检查通过，人工检查 10 个地图样张及实际采集、世界切换和跨区操作。浏览器验证使用本地演示及模拟 API；未调用真实外部 LLM，未将浏览器结果视为原生酒馆宿主验证。

### 0.3.1 区域生成格式修复

兼容模型地形行中的空格、全角字符、大写字母、单字符二维数组及逗号分隔。仅统一格式，不补格、不截断、不把未知字符替换为草地；边界、生态和连通校验继续执行。错误会指出具体行、实际格数或非法字符所在列。生成请求提供目标区域尺寸模板，并明确出发区域上下文与目标区域约束的区别。

59 项 Node 测试通过，新增格式兼容、坐标保持和错误诊断检查；没有取得用户此次失败的原始模型响应，无法确认其具体字符或行长。实际外部模型仍可能返回无效内容，失败不结算旅行。

### 0.3.2 诊断与调试

打开左侧 **06 诊断与调试**，或在错误提示旁点击 **查看诊断**。

- 查看区域/建筑生成、采集、建设描述、聊天同步、拉取模型和操作错误；首次生成与自动修正分开记录，以同一组编号关联。
- 显示请求状态、时间、耗时、模型、HTTP 状态、模型结束原因、原始接口响应、模型文本和目标生成约束。
- 按全部、异常或当前聊天筛选，支持单条/全部 JSON 报告导出、导出内容预览和清空记录。诊断页面不修改游戏状态，也不自动重试请求。
- 最近最多 30 条保存在当前用户的本地存储，总量约限制为 150 万字符；单个文本字段超过 60,000 字符时标记截断。刷新后保留，页面关闭前未完成的请求标记为中断。
- 不保存请求头或 API 配置，只保留模型、接口来源域名、超时和输出长度等信息；不记录角色卡背景、聊天请求正文或全部存档。已知密钥及常见凭据字段自动隐藏。模型响应本身可能包含剧情资料，请预览后再自行分享；不会自动上传。
- 诊断写入失败会提示并保留当前页面内的记录，不阻止原游戏请求。诊断只从更新后的操作开始记录，无法找回旧版已经丢弃的模型响应。

### 0.4.0 地块、资源点与洞穴

### 0.9.0 野生动物与生态活动

进入周边地块或洞穴后，在右侧 **附近生物** 查看当前可见动物，点击定位，或使用 **安静观察 · 5 分钟** 推进活动。地图以绘制的动物轮廓显示个体，历史观察单独保留，区域地图也能查阅该地块的观察记录。

- 首批基础物种：野兔、鹿、野猪、狐狸、狼、鼠、蝙蝠。由地理环境、聚落类型和洞穴筛选；暂用插件内固定物种目录，不调用 LLM 生成动物，不向封闭建筑生成野兽。
- 每种动物具有常态与奔跑速度、感知距离、饥饿、体力和活动时段。每分钟分四次交替推进，支持小数速度；奔跑消耗体力，移动受障碍和其他动物阻挡。动物不一定走满移动额度。
- 狐狸捕食野兔和鼠；狼还可追猎鹿、野猪。动物会感知、接近、追逐、逃跑和进食；失去视线后搜索最后位置，超过追踪时间或体力不足则放弃。尸体食物有限，一天后清理，死亡计数与唯一身份持久保存。
- 每 180 游戏分钟检查一次迁入机会，基础概率 55%，还需符合活动时段、区域储备和地点容量。小/普通/大地点最多 4/6/8 个活体，最多一个捕食者，捕食者迁入需有至少两个合适猎物。入口使用可通行的地图内侧边缘，离玩家至少四格。
- 区域各物种有共享迁入储备。清晨恢复：普通动物每天最多补 1，捕食者每天补 0.25；储备上限分别为 12 与 4。不是固定时间必刷，也不复活原来的动物。
- 离开地点后延迟结算，重返时保留原个体并计算可能迁出，最多补算最近一小时活动及两次迁入检查，避免长时间过夜后突然塞满地图。未探索地点不模拟实体。
- 脚印和捕食残迹保留四小时，观察记录保留一天。前端与聊天只提供当前可见动物、可见踪迹及明确标注的历史观察，不泄露隐藏的实时位置。
- 睡眠、移动、采集等游戏时间会推进动物；查看界面、等待 API、读档不重抽。旧存档无需重开，旧自然地点在下一次推进游戏时间时初始化。

范围：本版尚无玩家攻击、剥取、动物伤害玩家、群体协作、繁殖、噪声追踪、地形移速修正或营火驱兽。动物觅食暂不扣除玩家资源点物资；远处简化结算不逐分钟复现完整食物链。

验证：115 项 Node 测试通过，另以 50 个种子分别连续模拟两天并通过存档校验。浏览器验证动物绘制、观察推进时间和移动；6 项真实 IndexedDB 检查覆盖睡眠后恢复、非法写入回滚、跨区域导入、返回保留原个体、重返补算和存储失败回滚。浏览器使用模拟宿主，尚未完成原生酒馆与真实外部模型验证。


### 0.10.0 狩猎、尸体处理与烹饪

在地点地图点击动物或“附近生物”中的条目，详情出现对应操作。操作绑定个体 ID，远处或失去视线的目标不能被直接攻击；走近时动物仍会移动，需要重新确认。

| 操作 | 时间 | 体力 | 条件 |
|---|---:|---:|---|
| 检查活体或尸体 | 1 分钟 | 0 | 同格或相邻，结果进入日志 |
| 驱赶 | 1 分钟 | 3 | 三格内，按物种有不同成功率 |
| 基础近战 | 1 分钟 | 6 | 同格或相邻；徒手 1 伤害，有工具 3 伤害 |
| 割取一份生肉 | 5 分钟 | 2 | 已检查的尸体、工具、足够背包空间 |
| 剥取一份皮料 | 8 分钟 | 2 | 已检查的尸体、工具、足够背包空间 |
| 清理遗骸 | 3 分钟 | 1 | 同格或相邻，剩余物资直接丢弃 |
| 烤熟一份生肉 | 10 分钟 | 0 | 营火旁、已点燃且剩余燃料至少 10 分钟 |
| 皮料加工为布料 | 20 分钟 | 0 | 一份皮料和工具，产出一份布料 |

- 近战未击杀时有 50% 概率被反击；相邻驱赶失败也会反击。反击伤害：野猪 8、狼 6、鹿 3、狐狸 2，其余 1。成功驱赶会使动物尝试远离驱赶位置五分钟。工具不被消耗；动物尚不会主动攻击玩家。
- 新尸体的肉、皮产量由物种确定，捕食与玩家分割共用肉量。每次仅预留正在处理的一份，其他动物继续行动；没有无限重复剥取。旧尸体保留剩余肉，不额外赠送皮料。
- 死亡六小时后开始变质，十二小时后不可取肉，二十四小时后清理。检查显示新鲜度及剩余资源；腐败判断也用于操作开始前校验。
- 生肉不能直接食用，熟肉恢复 30 饱食。皮料加工得到布料，可用于已有的庇护所和火把配方。0.10 版本未实现背包腐败；0.12 已补充批次与保存系统，见下方更新说明。
- 所有操作由本地规则结算，不请求 LLM。时间、燃料、动物和饥渴正常推进；死亡时停止取得加工成品。存储失败回滚整次操作。

验证：124 项 Node 测试通过。浏览器验证完整的近战、尸体检查、取肉、剥皮、营火烤肉、皮料加工和食用流程；6 项真实 IndexedDB 检查覆盖恢复、重复操作、完整导入、失败回滚、材料加工和尸体清理。浏览器使用模拟宿主，原生酒馆与真实外部模型尚未验证。


### 0.11.0 装备、潜行与精神

- 随身背包增加武器装备与制作：石刀、木矛、石矛、简易弓、箭矢。装备引用背包物品，不另外复制；最后一件需卸下才能存入营地。旧存档保留原有工具攻击效果。

- 射击每次一分钟、4 体力和一支箭。两格内基础命中 90%，之后每远一格减 10 个百分点；潜行加 10 个百分点，低精神减 10 个百分点，最终 40%—95%。不因无耗时的界面/装备切换或导入增加的存档修订号重新抽签。箭暂不可回收，装备暂不设耐久。

- 石刀可替代旧工具处理尸体与加工皮料。制作需要材料、时间与负重空间；制作过程中角色死亡不产出成品。
- 玩家保留健康条，新增独立 0—100 精神条。清醒黑暗每小时 -2；地点内三格内可见狼/野猪每分钟 -2/60；反击每损失一点健康另扣 0.5 精神。照明燃尽和昼夜变化按分钟处理。
- 睡眠免除清醒压力，建筑/庇护所每小时 +6 精神，露天/洞穴 +3，露天小雨减半。提前醒来只计算已睡时间；预览、日志、聊天上下文与存档包含精神。
- 精神低于 25，普通行动基础体力消耗增加 25%，弓命中降低 10 个百分点；不直接死亡、不自动行动，固定攻击等成本不变。旧存档缺失精神时默认 100。
- 0.11 版本暂无人类 NPC、护甲、伤口、跑步、武器耐久和箭矢回收；0.12 已加入基础伤势。人类 NPC 的血条待实体系统加入。

验证：138 项 Node 测试通过；浏览器实际点击装备弓、潜行和射击，确认时间、体力、箭矢变化与动物逃跑。6 项真实 IndexedDB 检查覆盖读档、导入、失败回滚、睡眠恢复、旧窗口并发保护和伪造装备拒绝。浏览器使用模拟宿主，未验证原生酒馆与真实外部模型。


### 0.12.0 食物保存、庇护所设施与伤势

**食物批次**

- 普通食品初始七天、新采集浆果（仍显示为食品）两天、生肉上限十二小时、熟肉一天、熏肉七天。生肉继承尸体剩余新鲜度，烹饪/熏制继承原料加工结束时的新鲜比例。
- 同类食物按批次保存，优先使用能保持新鲜至操作结束的最早到期批次。腐败食物不能吃或加工，仍占重量，可丢弃。背包与营地显示可用/腐败数量和预计到期时间。
- 存取、离开区域、读档和完整导入不会刷新新鲜度。已搜索容器的食品同样计时；未搜索容器在首次搜索时确定物资。旧存档从启用新规则时统一计时，未加载的旧区域也沿用该时点。

**庇护所设施**

- 床铺：木材 3＋布料 3，六十分钟；睡眠每小时额外恢复 6 体力、2 精神，创伤休养速度加倍。
- 地窖：木材 4＋石料 6，一百二十分钟；营地储藏食物变质速度降到四分之一，建成前时间不回溯，容量仍为 200 kg。
- 工作台：木材 4＋金属零件 2，六十分钟；在营地制作武器和箭矢耗时减少 25%，向上取整。
- 灶台：石料 4＋金属零件 1，六十分钟；木材 1＋生肉 1，十五分钟烤出熟肉。
- 熏架：需要灶台，木材 3＋金属零件 1，六十分钟；木材 2＋生肉 1，一百二十分钟制成熏肉。
- 设施与材料保存在所在营地；操作需位于区域地图的营地。建设与加工仍推进生存时间，途中死亡不生成设施或成品。

**基础伤势**

- 动物反击伤害至少 2 时形成创伤和出血。创伤增加伤害的两倍（上限 100）；伤害 2—5 增一级出血，至少 6 增两级，上限三级。
- 每级出血每小时损失 0.6 健康，每级感染每小时损失 0.3。未止血累计每六小时加一级感染，上限三级；睡眠仍会失血。
- 创伤按数值百分比提高普通行动基础体力消耗，达到 30 时逐格移动额外一分钟，路径预览同步计算。
- 包扎消耗布料 1／五分钟：止血，不消除已有感染。医疗处理消耗医疗用品 1／十分钟：止血、清除感染、减少 20 创伤、恢复 10 健康。完成前仍可能失血致死，不会复活。
- 无出血感染且饥渴都高于 20 时，短休和睡眠每小时恢复 2 创伤，有床铺为 4。伤势提示常驻顶部，背包提供治疗入口，睡眠预览列出创伤变化。
- 无伤势时直接使用医疗用品仍恢复 25 健康；有伤势时使用治疗操作。三项系统加入百科、上下文、保存与导入校验。

暂未加入误食中毒、温度腐败系数、设施拆除、异步加工队列、身体部位与骨折。规则由插件本地计算，无新增模型调用。

验证：154 项 Node 测试通过；真实浏览器完成包扎、医疗处理、丢弃腐败食物、建设熏架与灶台烤肉。7 项真实 IndexedDB 集成检查覆盖食物/伤势/设施读档、完整导入、磁盘失败回滚、跨区域变质、多区域导入、旧窗口写入保护和伪造批次数量拒绝。浏览器为模拟宿主，原生酒馆与外部真实模型尚未验证。


### 0.13.0 开发者模式

在 **游戏设置 → 开发者模式** 开启，默认关闭，随当前游戏存档保存；切换聊天不会继承其他游戏的设置。

- 发放任意已定义物品，每次 1—10000 份，同类总量最多 10000；此入口允许超过背包负重，普通采集、制作和转移仍检查容量。食物以独立的新鲜批次加入，不刷新已有食物。
- 编辑并分别锁定健康、饱食、水分、体力、精神、创伤、出血与感染；锁定到填写的目标值。支持一键恢复全部状态（可复活）、清除伤势。
- 冻结游戏时间：行动照常产生结果、消耗材料，但时钟、食物腐败、照明燃料和动物的定时活动暂停；冻结时不能睡眠。已生成的地图仍可探索，新地图仍可生成初始动物。
- 解除冻结后可手动推进 1—10080 分钟，正常结算生存消耗与风险。
- 关闭模式会解除所有锁定，但保留已经发放的物品与修改后的状态。已导出的存档也包含开发者设置。

验证：164 项 Node 测试通过，覆盖数值锁定、时间冻结、食物批次、复活与写入失败回滚；浏览器模拟宿主验证设置面板，5 项真实 IndexedDB 检查通过，覆盖读档、导入、失败回滚、关闭模式和聊天隔离。未代替真实酒馆宿主与外部模型实测。

### 0.15.0 可走动与布置的 SVG 营地

从「我的庇护所」进入该地点的 15×15 营地。点击可见空地寻路，拖动平移、滚轮缩放；人物每格基础 1 分钟，接入体力、伤势、昼夜视距、墙门遮挡与随身照明。回到南侧入口后可离开。

当前为固定边界的独立营地地块；还没有占用既有建筑、边界扩建、屋顶或自动判定封闭房间。墙和门已参与通行与视线计算。所有操作由插件结算，不调用 LLM。
