# 地图图集

本项目美术由内置 imagegen 生成；工具不公开具体模型标识，未核验为 gpt-image-2.5。PNG 保留原始像素与透明通道，没有进行离线改色或图像重写。游戏从图集中按源矩形绘制，不需要外部图片服务。

| 文件 | 用途 |
| --- | --- |
| ground-v1.png | 16 种地表、浅深水、地板与墙材 |
| nature-v1.png | 树木、野外资源、岩石与洞口 |
| buildings-v1.png | 16 种建筑外观和地点备用图案 |
| furniture-v1.png | 容器空满、家具与工作台 |
| camp-v1.png | 营地设施、火堆和陷阱状态 |
| actors-v1.png | 7 种动物及尸体、玩家与 4 类 NPC |
| states-v1.png | 3 类作物的四个阶段、采尽的资源 |
| sample-v1.png | 用户此前认可的参考图集，保留山岭与树形变体 |

共 132 个可用切片，包含备用变体。并非每张图案都对应一种新增游戏地点；显示内容由已有地点类型与状态决定。`sample-v1.png` 是前一轮生成的原图，本轮未重新生成；其原始提示词未在本文件重建。本轮七张图集的完整提示词见 [prompts.json](prompts.json)。源矩形和图片尺寸见 [asset-data.js](../../src/asset-data.js)。

图集的实际尺寸和排布不完全等分，尤其动物与建筑。因此源矩形按透明边界单独测量；Canvas 与 SVG 都按同一矩形读取，并保留宽高比。墙角、丁字、十字和门窗使用程序精确拼接，避免生成图片的接口误差。

图片载入失败时使用原有程序图形。美术不会写入存档，也不会改变碰撞、资源余量、视野、建筑大小或行动时间。
